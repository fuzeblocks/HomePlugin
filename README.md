# HomePlugin

### A modern home and teleportation experience for Minecraft servers

HomePlugin brings homes, teleportation, warps and server travel tools together in one lightweight, flexible and player-friendly plugin.

## ✨ Everything your server needs for travel

HomePlugin is designed to make player teleportation simple, intuitive and enjoyable while giving administrators the tools they need to manage their server efficiently.

<td width="50%">

| **LuckPerms** | Manage permissions |

| **Server forks** | Compatible with most Paper and Spigot derivatives |

## 🎮 Simple commands, powerful features

| Command | Description |
|---|---|
| `/sethome` | Create or update a home |
| `/home` | Teleport to a home or open the home menu |
| `/homes` | Display all your homes |
| `/delhome` | Delete a home |
| `/renamehome` | Rename a home |
| `/relocatehome` | Move a home to your current location |
| `/spawn` | Teleport to the server spawn |
| `/tpa` | Request to teleport to another player |
| `/tpaccept` | Accept a teleport request |
| `/tpdeny` | Deny a teleport request |
| `/rtp` | Teleport to a random location |
| `/back` | Return to your previous location |
| `/warp` | Teleport to a server warp |

## 📦 Compatibility

- **Minecraft:** 1.14 and newer
- **Servers:** Paper, Spigot and derivatives
- **Java:** Java 8 or newer
- **Optional plugins:** Vault, LuckPerms and PlaceholderAPI
- **Storage:** YAML, MySQL and optional Redis caching

## 📥 Get started

1. Download the latest version from the [Releases](https://github.com/fuzeblocks/HomePlugin/releases) page.
2. Place the `.jar` file inside your server's `plugins/` folder.
3. Start or restart your server.
4. Enjoy a better teleportation experience.
